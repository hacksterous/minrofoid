# minrofoid
 Minimal plasmoid to run Rofi from a KDE Plasma panel.

 Clicking the icon will run the command `rofi -show drun`.
 You must have Rofi installed.

 Running install.sh copies the icon to ~/.local/share/icons/hicolor/scalable/apps/
 and installs the plasmoid.

 You must add the plasmoid to your panel in the usual Plasma way.
